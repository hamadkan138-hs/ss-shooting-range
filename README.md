# Pistol Shooting Competition: Registration Page

Live page: https://hamadkan138-hs.github.io/ss-shooting-range/

When someone fills in the form, WhatsApp opens with their details already typed in,
addressed to **0300-5730642**. They tap **Send**, and you confirm the slot and payment in that chat.
Each registration carries a reference number (e.g. `SS-LK3KO`) so you can track it.

## Changing details
Fee, venue and wording are plain text in `index.html`. To change the WhatsApp number that
receives registrations, edit `WHATSAPP:` near the bottom of `index.html` (format `923XXXXXXXXX`).
Edit on GitHub with the pencil icon and commit. The page updates within a minute or two.
