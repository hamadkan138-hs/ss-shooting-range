# Pistol Shooting Competition: Registration Page

Live page: https://hamadkan138-hs.github.io/ss-shooting-range/

When someone fills in the form, WhatsApp opens with their details already typed in,
addressed to **0300-5909040**. They tap **Send**, and you confirm the slot and payment in that chat.
Each registration carries a reference number (e.g. `SS-LK3KO`) so you can track it.

## Changing details
Fee, venue and wording are plain text in `index.html`. To change the WhatsApp number that
receives registrations, edit `WHATSAPP:` near the bottom of `index.html` (format `923XXXXXXXXX`).
Edit on GitHub with the pencil icon and commit. The page updates within a minute or two.

## Posting your daily reel (from your phone, 1 minute)
1. Post the reel on Instagram / Facebook / TikTok / YouTube Shorts as usual, then tap **Share → Copy link**.
2. Open https://github.com/hamadkan138-hs/ss-shooting-range/edit/main/reels.txt in your phone's browser.
3. Add a new line **at the top** (under the # lines) like this:
   `https://www.instagram.com/reel/ABC123/ | Clay plate challenge 💥`
4. Tap **Commit changes**. It shows on the website within 1–2 minutes, with a **NEW** badge.

The newest 12 reels are shown. Instagram, Facebook, TikTok and YouTube links all work.
Videos uploaded straight to the `reels/` folder also work: `reels/my-video.mp4 | caption`
(add a `reels/my-video.jpg` cover image with the same name if you like).
